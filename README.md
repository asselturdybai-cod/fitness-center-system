\# Фитнес-орталықты басқару ақпараттық жүйесі



Бұл жоба фитнес-орталықтың жұмыс процестерін автоматизациялауға арналған. Жүйе клиенттерді тіркеу, абонементтерді басқару, жаттығуларға жазылуды ұйымдастыру және кесте құру функцияларын қамтиды.



\## Негізгі функциялар:

\* Клиенттерді тіркеу және олардың профильдерін басқару.

\* Сатылатын және белсенді абонементтерді есепке алу.

\* Топтық және жеке жаттығуларға жазылуды ұйымдастыру.

\* Жаттықтырушылардың жұмыс кестесін қалыптастыру.
