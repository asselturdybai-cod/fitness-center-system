\# Қолдану сценарийлері (Use Case)



\## Use Case 1: Абонемент сатып алу

\* \*\*Актёр:\*\* Клиент, Администратор.

\* \*\*Негізгі ағын:\*\* Абонементті таңдау -> Төлем жасау -> Абонементті белсендіру.



\## Use Case 2: Топтық жаттығуға жазылу

\* \*\*Актёр:\*\* Клиент.

\* \*\*Негізгі ағын:\*\* Кестені ашу -> Жаттығуды таңдау -> Жазылуды растау.
